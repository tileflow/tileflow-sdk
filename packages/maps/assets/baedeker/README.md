# Baedeker visual references

The Baedeker map and the SVG patterns in `icons/` are original Tileflow code and artwork. Their
visual grammar is informed by late-nineteenth- and early-twentieth-century Baedeker travel maps and
town plans engraved by Wagner & Debes: open warm paper, fine coral building hatching, cyan water
engraved with horizontal lines, compact serif and italic type, dominant black railways, and public
gardens built from small open tree rings rather than broad green fills.

Reference collections:

- <https://www.antiquemapsandprints.com/collections/baedeker-karl-wagner-debes>
- <https://commons.wikimedia.org/wiki/Category:Maps_by_Karl_Baedeker_of_Italy>
- Moscow I, Wagner & Debes, 1914: <https://imperiia.omeka.fas.harvard.edu/document/2461>
- Amiens, Baedeker, 1908: <https://commons.wikimedia.org/wiki/File:Amiens_%E2%80%94_Plan_extrait_du_guide_B%C3%A6deker_%E2%80%9CNord-Ouest_de_la_France%E2%80%9E_1908.jpg>
- Berlin-Westend, Baedeker, 1914: <https://commons.wikimedia.org/wiki/File:Baedeker,_Plan_von_Westend,_1914.jpg>

No scan, raster pixel, historical typeface, legend artwork, geospatial data, or source map is
included or redistributed. The patterns were drawn from scratch as seamless intrinsic-size SVG
motifs for the Tileflow sprite pipeline. “Baedeker” is used descriptively for the historical
cartographic style; this map is not affiliated with or endorsed by the Baedeker publisher or the
reference collections.

The `fonts/` directory packages unmodified Cormorant Garamond Regular, SemiBold, and Italic at
pinned upstream revision `cc1bfb51ce6568cb3abf9199ab718d543f6fa189`. These files are Baedeker's
own package asset closure rather than a reference to Siegfried's copy. Cormorant is licensed under
the SIL Open Font License 1.1; the complete license remains beside the font files as
`fonts/LICENSE.txt`.
